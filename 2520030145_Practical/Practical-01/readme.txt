In this practical, I investigated the relationship between the hardware resources of a computer and the services provided by the Linux operating system. I used Linux terminal commands such as uname, lscpu, lsblk, ps, and top to understand how the operating system identifies, manages, and provides access to hardware resources. The uname -a command helped me view information about the Linux kernel, system architecture, and kernel version. This showed me that the Linux kernel is the main component of the operating system that communicates with and manages the hardware.
I used the lscpu command to obtain information about the CPU, including the architecture, number of CPU cores, and threads. From this, I understood that the operating system manages the physical CPU and provides CPU time to different processes using process scheduling. Applications do not directly control the processor; instead, the operating system decides which process should execute and for how long. I then used the lsblk command to view the storage devices and partitions available in the system. This helped me understand that Linux represents storage devices as block devices and provides filesystems through which applications can access stored data. An application does not need to know the physical location of data on an SSD or hard disk because the operating system handles the underlying storage operations.
I also used the ps command to view the processes running on the system. This helped me understand process management, where every running program is represented as a process and is assigned resources such as CPU time and memory by the operating system. The top command allowed me to observe processes and their CPU and memory usage in real time. Through this, I could see how different processes consume system resources and how the operating system continuously manages these resources.
From this practical, I understood that the operating system acts as an abstraction layer between applications and physical hardware. The CPU is abstracted through process scheduling, memory is managed using virtual memory and memory allocation, storage is accessed through filesystems and device drivers, and I/O devices are controlled by the operating system through appropriate drivers. This abstraction allows applications to use hardware resources without directly communicating with or controlling the physical hardware. Therefore, Linux provides a common and simpler interface to hardware while the kernel handles the complex operations required to manage the actual resources.
